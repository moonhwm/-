# 前缀复用报告 · 幻16 真机复核（distilgpt2 / CPU）

> data_cutoff: 2026-08-29 ｜ 复核人：Kimi (K3) ｜ 复核对象：`kv-cache-prefix-reuse-lab_2026-08-29.md`（沙盒玩具版）

## 复核结论：方向成立，量级如玩具版自警告那样下修

| 指标 | 沙盒玩具版（手写 4 层 attention，N=2048/M=64） | 幻16 真机（distilgpt2 完整模型，N=512/M=64） |
|---|---|---|
| 每轮节省 | 94.8% | **81.6%** |
| 单轮加速 | 19.1× | **5.4×** |
| 10 轮累计加速 | 6.9× | **3.7×** |
| 50 轮累计 | —（未测） | **5.0×** |

**差异归因**（实证支持玩具版 top3 第①条）：玩具 attention 无 FFN/归一化，cache 把它的历史成本几乎清零；真实模型的 FFN/投影在新 token 上照算，摊薄了复用收益。**量级下修但机制结论全部成立**：前缀只读一次、每轮只算新增、轮数越多 prefill 摊得越薄。

## 幻16 实测明细（torch 2.13.0+cpu，transformers 5.16.1，3 轮中位数）

- A 无缓存每轮全量重算（576 tok）：283.7 ms/轮
- B 前缀 prefill（512 tok，一次性）：237.6 ms
- B 增量（64 tok × 复用缓存）：52.3 ms/轮
- 注意：distilgpt2 最大位置 1024，玩具版 N=2048 超窗，复核用 N=512——这也是两者倍数不可直接对表的第二个原因

## 对 22h 项目判断的影响

玩具版的定性结论（长会话 = 缓存复用收益最大场景；官方侧必有前缀缓存但不暴露为可恢复检查点）在真机复核后**维持不变**；若引用数字，用真机口径（单轮 5.4× / 每轮省 81.6%）而非玩具口径（19.1×/94.8%）。
